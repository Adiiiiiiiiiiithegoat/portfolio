# Aditya Ranjith — Portfolio

Personal developer portfolio. A single static `index.html`: plain HTML/CSS/JS, no framework, no build step. Vercel serves it as-is.

Live: __SITE_URL__

## What's in the repo

| Path | What it is |
| --- | --- |
| `index.html` | The whole site: content, styles and the small theme/scroll script |
| `og.png` | 1200×630 social preview image, generated by `scripts/make_og.py` |
| `vercel.json` | Clean URLs, security headers, long cache for `og.png` |
| `scripts/make_og.py` | Regenerates `og.png` with Pillow (downloads Inter Tight + JetBrains Mono into `scripts/fonts/` on first run) |
| `scripts/screenshots.py` | Playwright screenshots at 1440/1024/768/390px in light and dark, flags horizontal overflow |
| `PLAN.md` | Build checklist |

## Editing content

All content is in `index.html`:

- **Hero and stats** → the `.hero` and `.stats` blocks at the top of `<main>`
- **Experience** → the `.job` blocks
- **Selected projects** → the `.card` blocks (add `wide` to make one span both columns)
- **More projects** → the `.row` blocks
- **Recognition** → the `.award` blocks
- **Stack** → the three blocks inside `.stack`

Colours are CSS variables at the top of the `<style>` block, with separate light and dark values. If you change the accent colour, update it in the favicon `<link rel="icon">` (`%232f5bea`) and in `scripts/make_og.py` too.

If you change the name, headline or awards, regenerate the preview image:

```
pip install pillow
python scripts/make_og.py
```

`og.png` is cached for a year, so social sites may keep the old one. Rename the file (and its two meta tags) if you need it to refresh immediately.

## Checking layout

```
pip install playwright && playwright install chromium
python scripts/screenshots.py                 # local index.html -> screenshots/
python scripts/screenshots.py https://… out   # any URL
```

## Deploy

The repo is connected to Vercel, so every push to `main` deploys to production. Manual deploy: `vercel --prod`.
